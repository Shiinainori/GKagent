# GKagent
帮助浙江省普通类高考学生准备的志愿填报skill，这里是样例，具体agent在coze
  GKagent/
  ├── SKILL.md                  # 主技能定义（含完整工作流）
  ├── config.json               # 技能配置
  ├── references/
  │   └── db_schema.md          # 数据库表结构说明
  ├── scripts/
  │   ├── gk_db_query.py        # 数据库查询脚本
  │   └── generate_excel.py     # Excel 生成脚本
  └── assets/                   # 输出目录（存放生成的 Excel）

  核心设计要点：

  - 专针对浙江省普通类，不区分文理，"专业+学校"平行志愿，最多 80 个志愿
  - 数据库字段仅包含：省份、学校代号、学校名称、专业代号、专业名称、选考科目要求、计划招生数、分数、位次
  - 工作流 7 步：收集校验 → 冲稳保三档查询 → 选考科目过滤 → 偏好排序 → 组装 80 志愿 → 生成 Excel → 返回下载链接
  - IF 条件覆盖：分数合法性、位次缺失查表、选科匹配硬过滤、偏好过滤、空结果回退、志愿数不足补充
  - 联网查询：知识库未覆盖时，查浙江省教育考试院 / 教育部，结合知识库信息综合回答
  - 冲稳保配额：冲 20 + 稳 40 + 保 20 = 80，不足时从相邻档补充
